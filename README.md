# Politique de confidentialité — Circuit Timer : Tabata, HIIT

*Dernière mise à jour : 27 octobre 2026*

Circuit Timer (« Circuit Timer : Tabata, HIIT » sur l'App Store) est une application iPhone de minuteur pour circuit training, développée par Yann Aleman.

## Données collectées

**Aucune.** Circuit Timer ne collecte, ne transmet et ne partage aucune donnée personnelle. L'application ne contient ni compte utilisateur, ni publicité, ni outil d'analyse, ni serveur.

## Données stockées sur votre appareil

Vos circuits, votre journal de séances et vos réglages sont enregistrés uniquement sur votre iPhone. Ils ne quittent jamais l'appareil, sauf par vos propres sauvegardes iCloud ou iTunes. Supprimer l'application supprime ces données.

## Apple Santé

Si vous l'activez dans les réglages de l'application, Circuit Timer **écrit** vos séances terminées dans l'app Santé sous forme d'entraînements (type « entraînement fractionné à haute intensité »), avec l'heure de début, de fin et les pauses. Circuit Timer **ne lit aucune donnée** de Santé. Vous pouvez retirer cette autorisation à tout moment dans Réglages ▸ Santé ▸ Accès aux données et appareils. Les données écrites dans Santé sont régies par la politique de confidentialité d'Apple.

## Notifications

Si vous programmez des rappels, l'application planifie des notifications locales sur votre appareil. Aucune notification n'est envoyée depuis un serveur.
